EMMANUEL ORBUNDE PORTFOLIO WEBSITE

index.html contains the website HTML, CSS, and JavaScript code.

To view it:
1. Keep index.html and the assets folder together.
2. Double-click index.html to open it in your browser.

To add your photo:
1. Copy your photo into the assets folder.
2. Name it my-photo.jpg.
3. In index.html, replace the photo placeholder with:
<img src="assets/my-photo.jpg" alt="Emmanuel Orbunde" class="profile-photo">

Edit index.html with Notepad, Visual Studio Code, or another code editor.
